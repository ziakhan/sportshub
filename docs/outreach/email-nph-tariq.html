Both buttons copy plain text. That is deliberate for an email body: with no styling attached, Gmail renders it in its own default font at its own size, so it looks like every other email you send.

Copying the text out of a chat window instead brings that window's dark background and font size with it, which is where the black block and the tiny type came from. If you ever do copy from somewhere styled, paste with Cmd+Shift+V to strip it.
